# Headway Learning Studio

Responsive Uzbek-language English practice website for Headway Beginner learners.

## Features
- Load the learner's Headway audio ZIP in the browser (MP3 files sorted by unit and track).
- Audio player with seek, 15-second skip, playback speed and repeat.
- 10-question Grammar, Vocabulary and Listening skills quizzes.
- Word Match, Sentence Builder and Flashcards games.
- Progress points and quiz totals saved locally in the browser.

## Run locally
Open \`index.html\` in a modern browser, or serve this folder with a static web server.

## Audio files
The repository intentionally does not redistribute the textbook MP3 files. Upload your own legally obtained ZIP from the Audio section. It is extracted in the browser and is not sent to a server or stored in this repository.

## GitHub Pages
In repository Settings → Pages, choose **GitHub Actions** as the build and deployment source. The included workflow deploys the static website on every push to \`main\`.
